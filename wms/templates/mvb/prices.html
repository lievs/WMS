Прайс

Цена за короб с градацией по количеству коробов: «от N коробов — X руб. за короб». Отправка на СЦ считается по каждому направлению заявки по прайсу его города (если у города нет своего прайса — по общему). Стоимость ставится при оформлении заявки, оператор может её поправить.

Пункты назначения

Сначала куда — WB, Ozon или фулфилмент, затем город, для ФФ — его название. Из этого списка клиент выбирает направление в заявке; по адресу водителю строится маршрут.
