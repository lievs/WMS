# Выход на коммерцию: материалы по порядку

Идите по этапам сверху вниз: каждый следующий опирается на предыдущий.

| Этап | Файл | Результат |
|---|---|---|

| 2 | [02-pilots.md](02-pilots.md) | профиль клиента, оффер, сообщения, план и критерии пилота |
